## Požadavky před instalací

- node v23.8.0
- npm v10.9.2
- gulp - CLI version: 3.0.0 / Local version: 4.0.2

## Inicializace repozitáře

- V rootu projektu spustit `npm install`

## Spuštění lokálního serveru

- V rootu projektu spustit `npm run dev`

## Formátování kódu

- HTML: `npm run prettier:html` - zformátuje HTML soubory dle konfigurace v souboru .prettierrc
- CSS: `npm run lint:scss`- zformátuje CSS soubory dle konfigurace v souboru .stylelintrc.json

## Defaultní knihovny

- Animate on scroll - umožňuje přidávat animace k elementům při jejich zobrazení na stránce, když uživatel scrolluje - (https://michalsnik.github.io/aos/)
- FontAwesome - umožňuje používat vektorové ikony na webových stránkách - (https://fontawesome.com/search?ic=free)
